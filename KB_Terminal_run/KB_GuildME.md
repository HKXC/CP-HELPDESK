# คู่มือการใช้เว็บ CP Helpdesk (User Guide)

> ระบบแจ้งซ่อมครุภัณฑ์/IT • อัปเดตล่าสุด: 2026-09-15
> เอกสารเทคนิค: `KB_web.md` (as-built) • สเปกหลัก: `SKILL2.md`

---

## 1. เริ่มใช้งาน

### 1.1 เปิดเว็บ (Docker — ไม่มี .bat แล้ว)

1. สตาร์ทฐานข้อมูล: `docker compose -f ../docker-compose.yml up -d` (ครั้งแรกตั้ง `POSTGRES_PASSWORD` ใน shell ก่อน; ถ้าใช้ native Postgres ข้ามข้อนี้)
2. ในโฟลเดอร์ `helpdesk/`: ครั้งแรกครั้งเดียว — ก๊อป `.env.example` เป็น `.env`, ใส่ค่าให้ครบ, แล้วรัน `npx prisma migrate deploy` + `npx prisma db seed`
3. รันเว็บ: `npm run dev:4502` แล้วเปิด `http://localhost:4502` ในเบราว์เซอร์เอง
4. เจอ `ERR_CONNECTION_REFUSED` = เซิร์ฟเวอร์ยังไม่ติด กลับไปข้อ 3

### 1.1b เปิดจากเครื่องอื่นใน Wi-Fi เดียวกัน (ไม่ต้องลงอะไรที่เครื่องนั้น)

1. ที่**เครื่องหลัก** (เครื่องที่รันเว็บ): รัน `npx next dev --port 4502 -H 0.0.0.0` ในโฟลเดอร์ `helpdesk/` (แทน `npm run dev:4502` ที่ฟังเฉพาะเครื่องตัวเอง)
2. หา IP เครื่องหลัก: รัน `Get-NetIPAddress -AddressFamily IPv4` (เช่นได้ `10.195.255.147` ณ 2026-09-15 — IP อาจเปลี่ยนถ้าย้าย Wi-Fi ให้เช็กใหม่)
3. ที่**เครื่องอื่น**: เปิดเบราว์เซอร์ไปที่ `http://<IP-เครื่องหลัก>:4502/login` เช่น `http://10.195.255.147:4502/login` แล้ว login ด้วยบัญชีเดิมได้เลย
4. ถ้าเข้าไม่ได้: ที่เครื่องหลักต้องเปิด firewall inbound พอร์ต 4502 ก่อน (ต้องใช้สิทธิ์ admin) + เช็กว่าอยู่ Wi-Fi วงเดียวกัน + เครื่องหลักเปิดเว็บค้างไว้

### 1.2 เข้าสู่ระบบ (`/login`)

- กรอก **อีเมล + รหัสผ่าน** แล้วกด `เข้าสู่ระบบ`
- หน้า login มีปุ่มลัด 3 ปุ่ม (`User` / `Tech` / `Admin`) กดแล้วระบบกรอกอีเมลให้ เหลือแค่พิมพ์รหัสผ่าน
- บัญชีทดสอบ (รหัสผ่านดูในไฟล์ `helpdesk\.env` ตัวแปร `SEED_*_PASSWORD`):

| บทบาท | อีเมล | ใช้ทำอะไร |
|---|---|---|
| ผู้แจ้ง (USER) | `user@jp.local` | แจ้งซ่อม + ติดตามงานตัวเอง |
| ช่าง (TECH) | `tech@jp.local` | รับงาน + ซ่อม + ปิดงาน |
| แอดมิน (ADMIN) | `admin@jp.local` | ทุกอย่าง + มอบหมาย + รายงาน |

- ล็อกอินสำเร็จจะพาไปหน้าแรก `/` ทุกครั้ง
- แถบบน (Topbar) ทุกหน้า: ช่องค้นหา (พิมพ์เลข Ticket/อาการแล้ว Enter จะพาไป `/track?q=...`), ชื่อ + บทบาทตัวเอง, ปุ่ม `ออกจากระบบ`
- เมนูซ้าย (Sidebar): กดปุ่มย่อ/ขยายได้ บนมือถือเป็นลิ้นชักเลื่อนออกมา

## 2. ผู้แจ้งซ่อม (USER) — ขั้นตอนใช้งาน

### 2.1 แจ้งซ่อมใหม่ (`/new-ticket`)

1. กดเมนู `แจ้งซ่อมใหม่` (หรือปุ่ม `+ แจ้งซ่อมใหม่` ในหน้าแรก)
2. กรอกฟอร์ม:
   - `หัวข้อปัญหา *` — สั้นๆ เช่น "คอมเปิดไม่ติด", "ปริ้นเตอร์กระดาษติด"
   - `หมวดอุปกรณ์` — คอมพิวเตอร์ / ปริ้นเตอร์ / เน็ตเวิร์ก / ซอฟต์แวร์ / ไฟฟ้าทั่วไป / อื่นๆ
   - `ความเร่งด่วน` — ต่ำ / ปานกลาง / สูง / ด่วนมาก
   - `รายละเอียดอาการ *` — อธิบายอาการ + สิ่งที่ลองทำแล้ว + ผลกระทบ
   - `เลขทรัพย์สิน (ถ้ามี)` — พิมพ์แล้วเลือกจากรายการ ระบบจะดึง Serial/ที่ตั้ง/Tags ให้อัตโนมัติ (ดูแผง `ข้อมูลครุภัณฑ์ที่เลือก` ข้างขวาประกอบ)
   - `สถานที่` — เช่น "ห้องบัญชี ชั้น 2"
   - `ช่องทางติดต่อ` — เช่น "โทร 1234" (ช่างจะได้ติดต่อกลับถูก)
   - `แผนก`, `ผลกระทบ (Impact)`, `ความเร่งด่วน (Urgency)` — กรอกได้ถ้ามี
3. กด `ส่งใบแจ้งซ่อม` ระบบจะพาไปหน้ารายละเอียดงานทันที พร้อมเลข Ticket (เช่น `HD-26-0001`)

### 2.2 ดูงานของฉัน (`/my-tickets`)

- เห็นเฉพาะงานที่ตัวเองแจ้ง
- ปุ่มฟิลเตอร์ 11 ปุ่ม: `ทั้งหมด / ใหม่ / คัดกรองแล้ว / ... / ยกเลิก` กดเพื่อกรองตามสถานะ
- กล่อง `เรียง`: เลือกเรียงតាមวันที่สร้าง / อัปเดตล่าสุด / ความสำคัญ / สถานะ + มาก→น้อย หรือน้อย→มาก
- กดที่การ์ดเพื่อเปิดหน้ารายละเอียด

### 2.3 ติดตามสถานะ (`/track`)

- ช่องค้นหาเดียว: พิมพ์เลข Ticket, หัวข้อ, อาการ, เลขทรัพย์สิน, หรือ Serial แล้วกด `ค้นหา`
- ผลลัพธ์กดเพื่อเปิดหน้ารายละเอียด (`/track/[id]`)

### 2.4 หน้ารายละเอียดงาน (`/track/[id]`)

สิ่งที่ผู้แจ้งเห็น:
- หัวข้อ + badge สถานะ + หมวด/ผู้แจ้ง/ช่าง + เลขเวอร์ชัน
- ไทม์ไลน์ 10 ขั้น + แถบความคืบหน้า
- กล่องรายละเอียด + การ์ดเลขทรัพย์สิน/Serial/สถานที่
- สรุปงานช่าง (`Diagnosis / Work / Parts / Resolution`) ถ้าช่างบันทึกแล้ว
- `ประวัติการดำเนินงาน` (เห็นเฉพาะข้อความทั่วไป โน้ตภายในของช่างจะถูกซ่อน)
- `ติดตามเพิ่มเติม / ถามช่าง`: พิมพ์ข้อความ + กด `ส่ง` (ช่างจะเห็น)
- `ไฟล์แนบ`: ดาวน์โหลดไฟล์ได้ + อัปโหลดเพิ่มได้ (ไฟล์ละไม่เกิน 10MB)
- เมื่องานอยู่สถานะ `แก้ไขแล้ว` หรือ `ปิดงาน` แล้วปัญหายังไม่หาย: กรอกเหตุผลแล้วกด `Reopen งานนี้` งานจะกลับมาเปิดใหม่

## 3. ช่างซ่อม (TECH) — ขั้นตอนใช้งาน

### 3.1 ดูงาน (`/technician`)

- เห็น 2 กลุ่ม: `งานของคุณ` (ที่มอบหมายให้แล้ว) + `งานรอรับ` (ยังไม่มีช่าง สถานะใหม่/คัดกรอง/มอบหมาย)
- การ์ดแต่ละใบโชว์ป้าย `ของคุณ` หรือ `รอรับ` + ผู้แจ้ง/สถานที่/ความสำคัญ
- กดที่การ์ดเพื่อเปิดหน้ารายละเอียดแล้วเริ่มทำงาน

### 3.2 ทำงานในหน้ารายละเอียด (`/track/[id]`)

แผงขวา `จัดการงาน (ช่าง/แอดมิน)`:
1. ช่อง `วิธีแก้ / บันทึกช่าง` + ช่องแยก `Diagnosis` (ผลวินิจฉัย), `Work performed` (งานที่ทำ), `Parts used` (อะไหล่ที่ใช้), `Resolution` (สรุปวิธีแก้) → กด `บันทึกโน้ต` (บันทึกได้โดยยังไม่เปลี่ยนสถานะ)
2. ช่อง `หมายเหตุการเปลี่ยนสถานะ` — เขียนกำกับทุกครั้งที่เปลี่ยนสถานะ
   - ติ๊ก `บันทึกเป็น internal` ถ้าเป็นเรื่องภายใน (ผู้แจ้งจะมองไม่เห็น)
3. ปุ่มเปลี่ยนสถานะ — ระบบโชว์เฉพาะปุ่มที่ไปต่อได้ตาม workflow (เช่น `กำลังซ่อม → รออะไหล่ / แก้ไขแล้ว`)
   - กดปุ่ม `ปิดงาน (CLOSED)` จะมีหน้าต่างยืนยันก่อนเสมอ เช็ค `Resolution` ให้ถูกก่อนกดตกลง
4. งานที่ยังไม่มีช่าง: กดรับงานได้จากคิว `งานรอรับ` (ช่างมอบหมายให้ตัวเองได้อย่างเดียว)

### 3.3 สถานะงาน 10 ขั้น (ดู badge แล้วรู้ว่าต้องทำอะไร)

| สถานะ | ความหมาย | คนที่ต้องขยับต่อ |
|---|---|---|
| ใหม่ (NEW) | เพิ่งแจ้งเข้ามา ยังไม่มีใครดู | แอดมินคัดกรอง |
| คัดกรองแล้ว (TRIAGED) | แอดมินตรวจ + จัดลำดับแล้ว | แอดมินมอบหมาย |
| มอบหมายแล้ว (ASSIGNED) | มีช่างเจ้าของงานแล้ว | ช่างเริ่มซ่อม |
| กำลังซ่อม (IN_PROGRESS) | ช่างกำลังทำ | ช่าง |
| รอข้อมูล (WAITING_REQUESTER) | รอผู้แจ้งตอบ/ส่งข้อมูล | ผู้แจ้ง |
| รออะไหล่ (WAITING_PARTS) | รอของ/ช่างนอก | ช่าง (ของมาแล้วกดกลับมากำลังซ่อม) |
| แก้ไขแล้ว (RESOLVED) | ช่างลงวิธีแก้แล้ว รอปิด | แอดมิน/ผู้แจ้งยืนยัน |
| ปิดงาน (CLOSED) | จบงาน | — (เปิดใหม่ได้ถ้าปัญหากลับมา) |
| เปิดใหม่ (REOPENED) | ปัญหากลับมา | แอดมินส่งช่างใหม่ |
| ยกเลิก (CANCELLED) | ยกเลิกพร้อมเหตุผล | — |

## 4. แอดมิน (ADMIN) — ขั้นตอนใช้งาน

### 4.1 จัดการงานทั้งหมด (`/admin`)

- แท็บ `งานทั้งหมด`: เห็นทุกใบของทุกคน + filter วันที่ `จาก–ถึง` + กล่อง `เรียง` + ปุ่ม `ก่อนหน้า/ถัดไป` (หน้า 20 ใบ)
- เปิดงานใบไหนก็ได้ → แผงจัดการมีเพิ่มส่วน `มอบหมายช่าง`: เลือกชื่อช่าง + กด `มอบหมาย` (มอบหมายให้ใครก็ได้ ช่างทำได้แค่รับงานตัวเอง)
- สถานะใหม่ (`NEW`) → กด `คัดกรองแล้ว (TRIAGED)` ก่อน แล้วค่อยมอบหมาย

### 4.2 รายงาน (`/admin?tab=reports`)

- กราฟแท่ง `สรุปตามสถานะ` (10 สถานะ) + ตาราง `สรุปตามหมวดอุปกรณ์`
- ปุ่ม `Export CSV` (มี BOM เปิด Excel ภาษาไทยไม่เพี้ยน) — ข้อมูลตาม filter วันที่ที่เลือก
- ใช้ดูงานซ้ำๆ เพื่อวางแผน PM/สต็อกอะไหล่

### 4.3 ผู้ใช้ (`/admin?tab=users`)

- รายชื่อผู้ใช้ทั้งหมด: ชื่อ / อีเมล / แผนก / บทบาท (อ่านอย่างเดียว)

### 4.4 ครุภัณฑ์ (`/assets` + `/assets/[id]`)

- ช่องค้นหา: พิมพ์เลขทรัพย์สิน / ชื่อ / Serial / ที่ตั้ง / Tags (เช่น `JP-PC-001`)
- กดชื่อครุภัณฑ์ → หน้า detail: ข้อมูลเครื่อง (ยี่ห้อ/รุ่น/แผนก/ผู้รับผิดชอบ/ประกัน) + `ประวัติซ่อม` กดย้อนดูใบงานได้
- เพิ่มเครื่องใหม่ (ADMIN เท่านั้น): ฟอร์มขวา `เลขทรัพย์สิน* / ชื่อ* / Serial* / หมวด / Tags (คั่นด้วย ,) / ที่ตั้ง` → `บันทึกครุภัณฑ์` (เลขซ้ำจะเตือน 409)
- ลบเครื่อง: กด `ลบ` (มีถามยืนยัน) — ถ้าเครื่องมีใบงานผูกอยู่ ระบบจะเปลี่ยนเป็น `RETIRED` แทนการลบจริง

### 4.5 Terminal (`/terminal`, ADMIN เท่านั้น)

- จอ console 4 บล็อกข้อมูลจริง: `status` (Web/DB/API latency) → `overview` (ยอดตามสถานะ) → `db --recent` (5 ใบล่าสุด) → `logs --tail` (20 บรรทัดล่าสุด)
- ว่าง = ขึ้น empty state ("ยังไม่มีข้อมูล") ไม่ใช่เลขศูนย์ปลอม
- บทบาทอื่นเปิดจะเจอ `⛔ เข้าถึงได้เฉพาะ ADMIN`

### 4.6 คู่มือ (`/knowledge`)

- บทความแก้เบื้องต้น 4 เรื่อง (คอม beep / กระดาษติด / Wi-Fi / ทิปแจ้งซ่อม) — แนะนำผู้แจ้งให้ลองก่อน ถ้าไม่หายค่อยแจ้งซ่อม

## 5. คำถามพบบ่อย (FAQ)

**Q: ลืมรหัสผ่านทำอย่างไร?**
A: ติดต่อแอดมินรีเซ็ตรหัสในฐานข้อมูล (รหัสเก็บแบบ hash กู้คืนไม่ได้ ต้องตั้งใหม่)

**Q: แนบไฟล์ไม่ได้?**
A: เช็ค 2 อย่าง — ไฟล์ต้องไม่เกิน 10MB และต้องมีสิทธิ์ในใบงานนั้น (ผู้แจ้งแนบได้เฉพาะงานตัวเอง)

**Q: หา Ticket ไม่เจอ?**
A: ใช้ `/track` ค้นด้วย Serial หรือเลขทรัพย์สินแทนหัวข้อ; บัญชี USER เห็นเฉพาะงานตัวเอง ถ้าเป็นงานคนอื่นต้องใช้บัญชีช่าง/แอดมิน

**Q: กดบันทึกแล้วขึ้น "Data was modified by another user"?**
A: มีคนแก้ใบงานเดียวกันพร้อมกัน (ระบบกันเขียนชนด้วย version) — รีเฟรชหน้าแล้วทำใหม่

**Q: เปลี่ยนสถานะแล้วไม่มีปุ่มที่ต้องการ?**
A: workflow ล็อกทางเดินไว้ (ดูตารางข้อ 3.3) เช่น ปิดงานได้เฉพาะจาก `แก้ไขแล้ว` — ต้องเดินตามขั้น

**Q: เปิดเว็บแล้วเจอ `ERR_CONNECTION_REFUSED`?**
A: เซิร์ฟเวอร์ยังไม่รัน กลับไปรัน `npm run dev:4502` ในโฟลเดอร์ `helpdesk/` ใหม่ (เช็กก่อนว่า DB ติดผ่าน `GET /api/health`)

**Q: ครุภัณฑ์ยังไม่ขึ้นทะเบียน แจ้งซ่อมได้ไหม?**
A: ได้ — พิมพ์เลข/Serial เองในฟอร์มได้เลย แล้วให้แอดมินผูกกับทะเบียนภายหลัง
