1. ภาพรวมสถาปัตยกรรม FRONTEND
----------------------------------------------------------------
- Next.js 16.3.4 (App Router) + React 19 + Tailwind CSS v4
  (`@import "tailwindcss"` ใน globals.css:1, ไม่มี tailwind.config / @theme)
- ทุกหน้าอยู่ใน src/app (route ตามโฟลเดอร์), หุ้มด้วย <AppShell>
  ยกเว้น /login (render เปลือย)
- Auth: cookie httpOnly `helpdesk_session` (8 ชม.) ตรวจ 2 ชั้น —
  (1) proxy.ts (middleware): PUBLIC_PATHS มีแค่ /login,
  /api/auth/login, /api/health นอกนั้นไม่มี cookie ดีดไป /login
  (หน้าเว็บ) หรือ 401 (API); (2) AppShell เรียก /api/auth/me
  ทุกครั้งที่เปลี่ยนหน้า ถ้าไม่ผ่านดีดไป /login
- ภาษา: <html lang="th">, ฟอนต์ Inter + Noto Sans Thai ผ่าน
  <link> Google Fonts ใน layout.tsx:14-19 (ยังไม่ใช่ next/font)
- ธีม: dark glassmorphism พื้น #0b0f1a + ambient glow 2 ดวง
